# NYC Mobility Big Data Platform

An end-to-end Data Engineering portfolio project using
public New York City taxi trip data.

## Project Goals

- Build reliable data ingestion and ETL pipelines.
- Process taxi datasets using Python and PySpark.
- Store analytical data using Apache Parquet and Delta Lake.
- Explore batch and streaming data processing.
- Implement data quality checks and workflow automation.
- Prepare analytics-ready datasets for taxi demand forecasting.

## Technology Stack

Planned technologies:
Python, SQL, PostgreSQL, Pandas, PySpark, Parquet,
AWS S3, Databricks, Delta Lake, dbt, Airflow,
Kafka, Docker, Terraform, GitHub Actions, and XGBoost.
